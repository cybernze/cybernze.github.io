# Carlos Agudo — portfolio

Live at https://cybernze.github.io

A board of my work: an intro you can chat with, then a canvas where each project plays as a short motion scene rebuilt from its real interface. Click **Inspect** on a project for what it is, how it flows, the stack and the numbers.

- **Tessera**: my startup, a regulatory assurance workspace for cybersecurity consultancies
- **Valuable**: company valuation from official French filings
- **DepoMind**: voice deposition practice against an AI witness
- **Bulletin Radar**: Spain's official bulletins as one API and a map (the scene plays the real dataset)
- **Latent Carriers**: my bachelor's thesis results (UPC)

Plain HTML, CSS and JavaScript. No build step. Chat answers are pre-written; no model is called.
